# Product Admin Dashboard

A responsive Product Admin Dashboard built with Next.js, React, TypeScript, Tailwind CSS, Axios, and the DummyJSON API.

## Features

- Login using DummyJSON authentication
- Protected product pages
- Logout functionality
- Product listing with:
  - Product image
  - Title
  - Category
  - Price
  - Rating
  - Stock
- Responsive desktop table and mobile card layout
- Search with debounce
- Category filtering
- Sorting by title, price, and rating
- Pagination with page size options of 10, 20, and 50
- URL-based page, search, filter, and sort state
- Product details page
- Product image gallery
- Product reviews
- Add new product
- Edit product
- Delete product with confirmation
- Form validation
- Loading, empty, error, and retry states
- Protected Add/Edit pages
- Protection against stale search responses
- Local persistence for product create, edit, and delete operations

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Axios
- DummyJSON API
